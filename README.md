# Lavanya Madan · Interactive AI Portfolio

Live site: [lavanya0505.github.io](https://lavanya0505.github.io)

An interactive portfolio for Lavanya Madan, AI/ML Engineer. It presents production-oriented work across agentic systems, RAG, LLM evaluation, research intelligence and MLOps.

## Experience

- Three.js / React Three Fiber neural hero scene with cursor response and ambient particles
- Framer Motion section reveals and project detail modal
- Project filtering across RAG, agents, MLOps and research
- Responsive navigation, theme switcher and mobile layout
- Evidence-led project metrics and technology stacks
- GitHub Pages deployment through GitHub Actions

## Development

```bash
npm install
npm run dev
npm run build
```

## Deployment

Every push to `main` runs `.github/workflows/deploy.yml` and publishes the Vite `dist` output to GitHub Pages.
